# Storybook

Запуск із кореня репозиторію: `bun run storybook`. Статична збірка: `bun run build:storybook`.

`main.ts` підключає React/Vite, Docs і перевірку доступності. Storybook не завантажує
`apps/web/vite.config.ts`, бо той конфігурує роутер, PWA та Convex для застосунку.
Натомість `vite.config.ts` у цій папці містить лише Tailwind і псевдонім `@`.
`preview.ts` підключає спільні глобальні стилі й токени. Історії `*.stories.tsx`
лежать поряд із компонентами; для складніших екранів використовуй детерміновані
дані з `src/shared/testing/fixtures` або локальні фікстури фічі.

У вкладці **Controls** змінюй аргументи вибраної story. Вкладка **Accessibility**
автоматично перевіряє активну story: спочатку переглянь **Violations**, потім
**Incomplete** (пункти, які потребують ручної перевірки). `a11y.test = "error"`
позначає порушення як помилки; CI-перевірка stories потребуватиме окремого
налаштування тестового раннера. Перевірка клавіатурою і на реальному екрані
все одно потрібна.

Складені stories використовують локальні фікстури фіч і не підключаються до Convex
або Сільпо. Дії через `fn()` видно у вкладці **Actions**, але вони не змінюють
серверний стан; для іншого стану вибери відповідну story. Stories з формами та
панеллю історії можуть запускати `play`, щоб заповнити поле або відкрити панель.
